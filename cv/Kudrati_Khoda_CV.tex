\section{Projects}
\begin{itemize}
\proj{Credit Risk Modelling \& Portfolio Stress Testing}{Python, scikit-learn, LightGBM}{LendingClub loan data, 2007--2018}
  \begin{itemize}
  \item Built PD models (Logistic Regression baseline, LightGBM challenger) on \textbf{1.34M resolved loans}, using only features available at origination (no leakage); out-of-time (2017) \textbf{AUC 0.70 / 0.71}, KS 0.29 / 0.30.
  \item Validated across 2015--2018 vintages with decile calibration, aggregate backtesting and PSI ($\leq$\,0.027); identified systematic PD underprediction in 2017 (\textbf{19.9\% predicted vs 23.1\% observed}, $\sim$5.4K excess defaults).
  \item Combined PD, realized LGD (93.3\%) and EAD to estimate portfolio \textbf{Expected Credit Loss of \$494.7M}; simulated correlated defaults (one-factor Gaussian, 10K loans $\times$ 2K scenarios) to obtain \textbf{VaR$_{99}$ \$68.5M} and ES$_{99}$ \$74.6M.
  \item Stress and sensitivity testing: PD odds $\times$1.5 with LGD +5\,pp raised VaR$_{99}$ to \$83.0M; raising default correlation $\rho$ from 0 to 0.5 increased VaR$_{99}$ \textbf{3.6$\times$} (\$30.5M $\to$ \$108.4M), showing dependence as the key driver of tail risk.
  \end{itemize}
