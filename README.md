# Short-Horizon Signal Research: Crypto Markets and Prediction-Market Settlement

Research question (to be finalised in Task 2):
can information available at time *t* give a statistically robust signal for short-horizon
returns, and does that signal survive transaction costs and out-of-sample testing?

The answer is **not assumed to be yes**. Failed hypotheses are reported as failed.
